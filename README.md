# رعاية كبار السن

تطبيق Android واحد لكبار السن وأفراد الأسرة، بواجهة عربية مبسطة، وإمكانية اختيار الإنجليزية.

## نطاق الإصدار الأول
- ملف شخصي مستقل للمسن، مع بيانات الحساسية والأمراض وجهة اتصال الطوارئ.
- تسجيل الأدوية ومواعيدها وتذكيرات محلية على الجهاز.
- تسجيل حالة الجرعات: مؤكدة / لم تؤخذ / غير مؤكدة.
- سجل يومي للأدوية والمواعيد والقياسات.
- قياسات الضغط والسكر والوزن والحرارة.
- مواعيد الأطباء والفحوصات.
- حفظ ملاحظات الأدوية والروشتات محليًا.
- زر SOS بالضغط المطوّل، مع رسالة طوارئ جاهزة لجهة الاتصال.
- بطاقة طبية للطوارئ قابلة للمشاركة.
- تكبير الخط والوضع الداكن الاختياري.

## ملاحظات مهمة قبل الإطلاق العام
هذا الإصدار هو تطبيق Android محلي (offline-first). المزامنة الفعلية بين أجهزة الأسرة، دعوات الربط عبر كود/رابط، وإشعارات الطوارئ البعيدة بصوت متكرر تحتاج خدمة خلفية موثوقة وإعداد مفاتيح Push Notifications؛ لا يتم الادعاء بأنها تعمل في هذا الإصدار. تنبيهات الدواء تعتمد على صلاحيات وإعدادات Android، وقد تتأثر بقيود الشركة المصنعة ووضع توفير البطارية. زر SOS يفتح تطبيق الرسائل برسالة جاهزة ولا يرسل SMS دون موافقة المستخدم.

## بناء APK
يتم بناء APK تجريبي تلقائيًا عبر GitHub Actions عند كل Push إلى `main`، ويمكن تنزيله من تبويب Actions > أحدث عملية ناجحة > Artifacts.
